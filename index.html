FIAP - Projeto DevSecOps

Pipeline de segurança utilizando GitHub Actions e Docker.

Objetivo

Este projeto aproveita a base do CP04 de Containers para demonstrar verificações de segurança automáticas em um repositório GitHub.

Tecnologias utilizadas

  • HTML: página web simples.
  • Docker e Nginx: execução da página em um container.
  • Gitleaks: detecção de segredos expostos em commits.
  • Semgrep: identificação de código vulnerável, como o uso de eval().
  • Trivy: análise de vulnerabilidades críticas na imagem Docker.
